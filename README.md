# 💜 Homenagem Especial para Sabrina Campelo

Um projeto desenvolvido com carinho, criatividade e dedicação, transformando uma simples página web em uma experiência digital interativa, delicada e cheia de significado.

A proposta é proporcionar uma experiência especial por meio de mensagens personalizadas, animações, efeitos visuais e pequenas surpresas ao longo da navegação.

## ✨ Sobre o projeto

O site foi desenvolvido utilizando **HTML5, CSS3 e JavaScript puro**, sem frameworks ou bibliotecas obrigatórias.

A identidade visual combina uma atmosfera romântica com elementos de galáxia, cores delicadas, iluminação, efeitos animados e cartões inspirados em cartas especiais.

Cada etapa da navegação foi pensada para criar uma experiência envolvente, com surpresas que são reveladas progressivamente.

## 🚀 Recursos e funcionalidades

- **Experiência interativa:** navegação entre diferentes telas e etapas da homenagem.
- **Leitor biométrico animado:** efeito visual de leitura com preenchimento em verde antes de revelar o conteúdo.
- **Cartões em formato de cartas:** mensagens organizadas em apresentações delicadas e personalizadas.
- **Animações CSS:** transições, efeitos de entrada e elementos visuais animados.
- **Atmosfera de galáxia:** identidade visual inspirada no universo e nas estrelas.
- **Música de fundo:** trilha sonora integrada para acompanhar a experiência.
- **Mensagens personalizadas:** declarações, desejos de felicidade e textos especiais.
- **Surpresas interativas:** revelações ao longo da navegação, incluindo uma carta divertida sobre um litro de açaí.
- **Integração com Pix:** botão para copiar a chave Pix com apenas um clique.
- **Layout responsivo:** adaptação para computadores, tablets e celulares.

```text

│
├── index.html       # Estrutura das telas e mensagens
```

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.
4. Aproveite a experiência completa.

Não é necessário instalar dependências ou utilizar frameworks.

## 🎨 Personalização

O projeto permite personalizar facilmente diferentes elementos:

- **Nome:** altere as referências à Sabrina no arquivo `index.html`.
- **Mensagens:** edite os textos presentes nas seções da homenagem.
- **Cores:** modifique as variáveis e propriedades do arquivo `style.css`.
- **Animações:** ajuste os efeitos e tempos das transições no CSS.
- **Interatividade:** personalize os comportamentos e eventos no `script.js`.
- **Música:** substitua `musica.mp3` pela trilha sonora desejada, mantendo o caminho atualizado.
